## Contents

- `entry.png` — the news front page image (1024×1024 PNG)
- `page.html` — the HTML source used to render the image
- `main.ts` — Node script that copies `entry.png` to `$MAKEFUN_OUTPUT_DIR`

## Usage

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Built with a headless Chrome screenshot of an HTML/SVG page — no AI image generation.
